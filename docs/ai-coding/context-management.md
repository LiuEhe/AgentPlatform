# 上下文管理

长期规则放在仓库文档里，任务进展放在任务记录里，不能只靠聊天摘要恢复。

## 长期文档

以版本化的 AGENTS.md、治理文档、README 和已接受的技术决策记录（ADR）为准。实现变化时同步相关内容；涉及新架构主张时先走[治理流程](governance.md)。规划必须标为规划，不能写成已实现或已批准。

## 任务记录

多步骤或跨会话任务记录以下内容：

- 目标、范围、约束、批准状态与验收条件；
- 已查看的文件、计划进度与关键决定；
- 已修改文件、已执行检查及结果；
- 未解决问题、风险和下一步。

优先使用已有任务或 PR 记录。确需跨会话且没有载体时，可新增简短任务说明；结束后不保留无用途的进度文件，清理仍遵守文件删除审批规则。任务记录只引用长期规则，不复制整套规则。

## 恢复任务

先读 AGENTS.md、相关规则、任务记录和 Git 状态，再核实“已完成”的内容。保留原始约束和未执行项，不能把建议变成批准、未运行变成通过。

摘要与仓库不一致时，以当前代码、版本化文档和用户明确决定为依据，并报告差异。重要决定改变后同步持久记录。
