# 架构规则

项目架构、目录和模块清单见[项目架构目录](project-structure.md)。本文只维护职责边界、依赖约束和架构变更要求；具体功能、接口、配置和操作步骤由相关 README 与专题文档维护。

## 依赖边界

| 层或模块 | 约束 |
| --- | --- |
| 后端 `api/` | 处理 HTTP 输入输出与身份依赖，业务用例委托给服务层 |
| `services/` | 协调上传、执行、取消、导出等应用用例；模块按 `*_service.py` 命名，不承载 Agent 意图、业务路由或存储实现 |
| `runtime/` | 保持通用注册、调用与执行协议，不依赖具体 Agent 的业务规则、HTTP 或会话存储 |
| `agents/<agent>/` | 承载专属图、业务状态、意图、参数和节点；通过注入的能力调用外部系统，不反向依赖应用服务、账号或会话存储 |
| `nodes/` | 承载确有复用需求的公共处理能力，不混入特定 Agent 的材料选择或审核策略 |
| `infrastructure/` | 封装供应商 SDK、数据库和文件存储，不编排 Agent 业务或返回 HTTP View |
| `schemas/` | 放置应用共享数据契约；Agent 私有输入输出和状态留在对应 Agent 包 |
| `core/` 与 `main.py` | `core/` 提供配置、错误和中立观测接口；`main.py` 装配并注入资源，业务模块不自行重复创建客户端 |
| 前端 `views/`、`features/`、`api/` | 页面负责组合，feature 承载业务交互，后端访问统一经过 API 客户端；前端不承担后端 Agent 的意图识别或业务编排 |

## 容易混淆的职责

| 主题 | 划分要求 |
| --- | --- |
| Agent 状态与会话存储 | 业务图状态归 Agent 的 `graph/state.py`；短期消息、摘要及待补参随 Agent 图由官方 checkpointer 持久化；完整历史、附件、运行记录归业务存储实现，活动通知、临时文本和锁归进程内活动资源管理，不维护第二份完整历史快照或业务 continuation |
| 文档处理 | 格式解析复用 `nodes/document/`；上传、保存、取消和资源额度由应用服务协调，材料角色与使用方式由 Agent 判断；避免重复解析 |
| 上下文与 Prompt | 公共预算计算、输入裁剪、有界分片摘要和 Prompt 解析契约归 `nodes/llm/`；材料选择、任务模板、输出结构和动作校验归 Agent；供应商适配归基础设施 |
| Agent 间调用 | 通过注入的运行时调用能力复用已注册 Agent；数据库展示记录不授予执行能力，注册期间不执行任务 |
| 数据库访问 | 驱动和连接池由 `infrastructure/database.py` 管理；身份与会话仓储通过 `BaseDatabase` 共享连接池，跨仓储的身份校验与写入复用同一事务连接；业务 SQL 和拥有者判断仍归仓储；官方 AsyncPostgresSaver 是受限例外，由 infrastructure/conversation/checkpoints.py 管理独立 Psycopg 池，和业务池使用同库同 schema，不对业务 SQL 开放旁路 |
| 文件与删除 | 本地文件实现负责文件读写和精确清理，应用服务协调业务数据库、官方检查点与文件操作；永久删除通过共享 thread_id 与官方 adelete_thread 清理记忆，不进入 Agent 图或 runtime，数据库提交未确认时不盲删文件 |
| 文档导出 | 由导出服务和基础设施转换程序完成，独立于模型配置；不放入审核图或 AgentRuntime |
| 可观测性与评估 | 中立接口归 `core/`，供应商 SDK 归基础设施，任务评估规则归 Agent；追踪不替代会话存储，不改变业务响应，也不自动采集真实文档作为数据集 |

## 执行与数据约束

- LangGraph 用节点与条件边表达流程；动态分块优先采用官方 `Send` / Map-Reduce。明确并行状态的合并语义，业务结果按序号排序，汇总等待全部所需分支。
- 区分图内并发、同进程跨请求额度和跨进程额度；`max_concurrency` 不能替代共享资源限额。重试、流式输出和断点恢复优先复用框架能力，不据此宣称已有持久恢复。
- 模型、文档解析和 SSE 等待不持有长数据库事务；终态结果提交成功后才通知客户端完成。流式订阅只读取已有运行，断开订阅不等于取消后台任务。
- 登录身份由服务端校验，会话及子对象按拥有者隔离，管理员不绕过归属判断。前端身份变化时清理私有页面状态，认证 token 与 CSRF token 不写入 Web Storage。
- 记忆执行只接收当前轮输入，从业务已提交 checkpoint_id 延续；成功归档与指针同事务，失败/取消/中断不推进。运行时只透传中立 resources，子 Agent 不自动继承材料 reader。各会话助手共享 saver 与公共摘要机制，状态、Prompt 和业务策略独立。
- 数据库历史、官方检查点、本地附件和进程内活动任务分别管理；当前运行方式、初始化及恢复边界见[数据库说明](../database.md)，不能将历史持久化等同于任务可恢复。

## 复用与架构变更

1. 修改前检查已有实现、实际调用方和锁定版本的官方能力；优先复用现有模块，不为一次转发或假设的未来需求增加抽象。
2. 新增或迁移文件时说明职责、输入输出、依赖和实际调用方。新增顶层目录、后端或前端一级模块、架构模式、基础设施或公共契约变化，按[治理流程](governance.md)提交问题、方案、替代方案和影响，经用户确认后实施。
3. 当前实现与拟变更分开描述；获准实施后同步受影响的架构说明、README 和检查。正式文档引用源码、部署资产和治理文档，不依赖任务设计或执行记录。

功能与运行说明见[后端 README](../../backend/README.md)和[前端 README](../../frontend/README.md)；错误响应见[错误码](../errors.md)，验证要求见[质量门禁](quality-gates.md)。
