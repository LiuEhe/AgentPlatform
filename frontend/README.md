# AgentPlatform 前端

使用 Vue 3、TypeScript、Vue Router 和 Vite。页面调用真实后端接口，图标复用 `@lucide/vue`。

## 本地运行

需要 Node.js 20.19+ 或 22.12+、pnpm。以下命令在 `frontend/` 执行：

```powershell
Copy-Item .env.example .env.local  # 仅首次执行，已有配置时跳过
pnpm install --frozen-lockfile
pnpm dev
```

后端启动见[后端说明](../backend/README.md)。Vite 默认把 `/api` 转发到 `http://127.0.0.1:8000`；使用其他入口时设置 `VITE_API_BASE_URL`。模型和知识库凭据只放在后端。

浏览器里看到 `localhost:5173/api/...` 是正常的代理地址。就绪检查通过但模型调用失败时，检查后端网络、模型配置与任务错误码，无需因此修改前端代理或 CORS。

## 页面入口

| 路径 | 用途 |
| --- | --- |
| `/` | 平台介绍 |
| `/agents` | 智能体目录，名称和描述来自后端 |
| `/agents/conversation-assistant` | 聊天、会话记录和附件 |
| `/agents/institution-review` | 草稿与标准文档或知识库审核、报告与 Word 下载 |
| `/agents/institution-review/flow` | 静态流程图，不表示实时进度 |
| `/login`、`/register` | 登录、公开注册；注册后仍需登录 |
| `/account`、`/account/password` | 个人资料、头像和改密 |
| `/admin/users` | 管理员账号管理与只读资料详情 |

公共页面使用顶部导航；助手左栏只管理会话，移动端收进抽屉。未知智能体提供返回目录操作。目录加载失败可重试，图标和已知工作入口由前端定义。

## 聊天、草稿与历史

助手支持普通聊天、追问、粘贴正文和可选 DOCX，审核意图与补参由后端判断。选择附件后立即上传，发送时再将文件 ID 关联到消息。

| 操作 | 行为 |
| --- | --- |
| 输入 | Enter 发送，Shift+Enter 换行；确认中文输入法候选不发送 |
| 只发附件 | 自动提交“请查看我上传的文件。”作为正文 |
| 发送成功 | 清空本轮附件选择，消息保留真实文件名 |
| 网络失败 | 保留输入和附件；响应丢失或 5xx 重试复用原客户端消息 ID |
| 新建或切换会话 | 保留旧会话与各自草稿；完全空白且无请求、任务或错误的当前会话可复用 |
| 离开助手页 | 中止客户端请求和订阅，后台任务继续；回来后重新读取并订阅原任务 |
| 点击停止 | 调用取消接口，以后端返回的最终状态为准 |

连接或创建期间忽略重复新建；切换期间禁止停止旧任务，迟到结果不能写入别的会话。Vue KeepAlive 在同一身份导航时保留助手页面内存。

**刷新后能恢复**：后端保存的消息、标题、文件信息和结果。文件原件与解析正文在后端文件目录。列表和消息分页读取，可加载更早内容；增量读取使用 after 游标，不能用全局 `last_sequence` 跳过未读页。

**只在页面内存里保留**：助手未发送草稿和附件选择；独立审核页另保存待提交的原始文件。`sessionStorage` 仅按已核验用户 ID 保存当前会话、幂等消息指针及待重试删除 ID/phase，不存正文、Cookie 或 CSRF。刷新优先恢复当前会话，否则读最近会话；无历史时显示空态，点击新建才创建。后端重启中断的任务不会自动重发。

## 流式回答与重连

发送后使用原生 `EventSource`，不定时轮询。普通聊天逐步显示模型文字，审核显示阶段与完整报告：

| 事件 | 页面处理 |
| --- | --- |
| `snapshot` | 替换累计临时回答 |
| `delta` | 追加文字 |
| `state` | 更新阶段 |
| `done` | 用正式消息替换临时回答，关闭订阅 |

临时文本也经 Markdown 和 DOMPurify 渲染，失败或取消不会显示成成功回答。重连按服务端给出的 3 秒间隔进行；连续三次错误或永久连接错误后，关闭订阅并查询一次 JSON 状态，再提示手动重连。重试订阅同一任务，不重新提交消息。临时文本恢复限同一后端进程，历史最终结果可从数据库恢复。

查询 HTTP 200 不表示执行成功，还要看任务 `status` 和 `error.code`。例如 `CONVERSATION_INTENT_FAILED` 应检查后端模型调用，更多见[错误码](../docs/errors.md)。

## 永久删除会话

确认后删除会话、消息、运行结果、检查点和附件；上传、运行或后台收尾期间暂不能删除，不隐式停止任务。

只有 DELETE 返回空 204 才算全部完成。清理未完保留“重试清理”，提交结果未知时仍用原 ID 重试，不重发消息。删除当前会话后恢复最近剩余会话，无历史时保持空态；删除其他会话不关闭当前订阅或清除草稿。

待重试项使用 `agent-platform-session-deletions` 键并按用户隔离，仅存 ID/phase。身份清理时移除旧的三个无用户归属键。

## 制度审核与报告

工作台默认“标准文档”，需同时选草稿和标准；切换知识库时清空标准选择。文件可选择或拖放，前端检查 DOCX 扩展名和空内容，后端负责实际解析及容量校验；提交中不能改材料或方式。

请求使用 FormData 的 `file/review_mode`，标准模式另加 `standard_file`，同步返回完整 Markdown。后端默认仍为知识库，前端始终显式提交方式。

“停止等待”或离开审核页只中止页面等待并忽略迟到结果，不撤回服务端审核；材料保留，再提交从头执行。这与聊天里的“停止”不同。

报告经 marked Renderer 生成章节定位，再由 DOMPurify 清理；不推断风险数量或删减正文。复制使用完整原始 Markdown，剪贴板不可用时提供手动复制。Word 下载是独立请求，失败保留报告并可单独重试，不重新审核；切换报告或离开页面会取消未完成的下载。

## 账号与身份切换

账号菜单提供资料、改密、管理员入口及退出确认。个人资料支持显示名称、头像、邮箱、性别、生日、手机号、地址和签名；资料页 `user_id` 标签展示用户名，接口里的 `user_id` 仍是 UUID。临时密码用户须先改密，再重新登录。管理员可只读查看内置 admin 和停用用户的资料，没有代编辑入口。

头像先裁剪、确认后上传；上传状态未知时重读本人资料，只同步头像状态，不覆盖文字草稿。确认失败可重试确认，确认前禁止重复头像写入。同一身份重新核验后，头像会重新读取。

认证由 `features/auth/useAuth.ts` 统一管理，HTTP 客户端绑定 credentials、CSRF、登录上下文和身份代次（用于识别旧请求）。SSE URL 只传公开上下文 ID；认证恢复不重放业务请求。

- 退出、换号、401 或上下文冲突：卸载私有页面与缓存，清除草稿、附件、会话快照、重试项、位置和 Blob URL；旧响应不能交付内容或使新账号退出。
- 页面隐藏或恢复：先遮蔽私有内容，核验登录后再展示；网络或数据库故障时保持遮蔽并禁写，确认原登录后可恢复内存。
- 退出网络失败：本地内容先清空，保留同源非敏感退出锁；刷新不自动恢复，可重试或输入密码重新登录，重试不撤销别的标签页新登录。
- 跨标签页：用随机 storage 信号触发重新核验；禁用存储时提示降级，不能保证跨刷新锁定。

## 开发与检查

删除对话、退出登录、账号停用/启用及停止等待审核共用 `components/ConfirmDialog.vue`。组件只负责确认界面：默认聚焦取消，Esc 和右上角关闭均取消，点击遮罩保持打开，关闭后恢复触发位置；危险操作为红色确认，普通操作为深色确认。

业务动作仍由各页面处理；账号确认绑定打开时的目标与身份，审核结束会关闭过时的停止提示。头像裁剪、用户资料、创建用户及重置密码仍使用各自专用界面。

代码分工：`views/` 组合页面，`features/` 管业务交互，`api/` 管 HTTP/SSE，`components/` 放共享组件。会话的 `useConversation.ts` 协调页面状态，`conversationSnapshots.ts` 管草稿及会话快照，`conversationDeletions.ts` 管删除请求与清理重试。

`App.vue` 管公共外壳与缓存；`style.css` 保留主题、基础和公共样式，账号、会话、审核及公共页面 CSS 放在各自目录，由 `main.ts` 按固定顺序加载，保持页面切换前后的样式一致。认证使用 Vue provide/inject，未引入全局状态管理库。完整路径见[项目目录](../docs/ai-coding/project-structure.md)。

在 `frontend/` 运行：

```powershell
node --test
pnpm build
```

Node 内置测试复用已有 Vue/TypeScript；构建包含类型检查。CI 只运行指定的 Node 用例及构建，具体范围见[质量门禁](../docs/ai-coding/quality-gates.md)。真实浏览器的多标签页、输入法、手机布局、Canvas/dialog，以及模型、文件解析、知识库和 Word/WPS 版式仍需对应环境验收。
